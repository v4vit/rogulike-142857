# 无尽塔防 —— 设计文档

## 一、地图
- **40 × 40 网格**，每个格子 24px，画布 960×960（另有右侧 UI 栏）。
- 怪物从**地图右侧**（最右列）杀入，向左行进，目标是**主基地**（核心）。
- 场上存在「道路/通行」与「可建造」两种格子：塔只能建在可建造格，怪物沿可通行格行进。

## 二、怪物（跳动圆球，四色，生命一致随波数成长）
| 颜色 | 名称 | 体型 | 移速 | 权重 | 特性 |
|------|------|------|------|------|------|
| 🔴 红 | 标准型 | 正常 | 中 | 1 | 基准 |
| 🟢 绿 | 坦克型 | 大 (1.5x) | 慢 (0.6x) | 3 | 皮厚走慢 |
| 🔵 蓝 | 敏捷型 | 小 (0.7x) | 快 (1.5x) | 2 | 走快体积小 |
| 🟡 黄 | 复生型 | 正常 | 中 | 2 | 死亡后原地复活为一只红色标准型 |

> 生命一致：同波所有怪基础生命相同，随波数成长（`15 + 3*波数`）。

## 三、出怪机制（植物大战僵尸式）
- 每只怪有一个**权重**（见上表）。
- 每波设一个**总权重** W，系统**随机出怪**（红/绿/蓝/黄按权重分布），累计已出权重 ≥ W 时**停止本波出怪**。
- 当**场上剩余怪物的总权重 ≤ 本波总权重的一半**时，自动**刷新下一波**，总权重随波数递增。
- 无尽模式：波数无上限，每波 W 按公式增长，能量/怪物强度逐渐提高。

```
W(波数 n) = 8 + 3*n            // 每波总权重
怪物血量 = 15 + 3*n              // 随波数成长
怪物移速 = 基础 * (1 + 0.02*n)
```

## 四、塔（占地由设计者设定）
| 塔 | 占地 | 能量成本 | 射程/功能 |
|----|------|---------|-----------|
| 主基地（核心） | **2×2** | — | 血量400，被摧毁则游戏失败 |
| 太阳能塔 | **1×1** | 40 | 连续产出能量（2/秒） |
| 机枪塔 | **1×1** | 60 | 攻击射程内敌人（射程3格，DPS≈28） |

- 能量上限 400，初始 200，由太阳能塔补充，用于建造。
- 主基地血量 400；怪物到达基地攻击它，归零则失败。

## 五、操作
- 选择下方工具栏的塔 → 在绿色可建造格点击放置。
- 键盘：1/2 选择塔，空格 暂停/继续，Esc 取消选择。
- 每波开始时自动出怪，场上权重降到阈值即开下一波。
